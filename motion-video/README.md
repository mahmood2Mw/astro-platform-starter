# فيديو موشن جرافيك: أساسيات الحاسب الآلي الشاملة (معهد اليقين الدولي)

فيديو إعلاني عمودي لشاشات الهواتف: 1080×1920 (9:16)، ‏30fps، ومدته **30 ثانية**. بُني بـ Remotion.

الملف الجاهز: `export/alyaqin-promo.mp4`

## الهوية
- **الشعار:** شعار المعهد الخطي الحقيقي، مستخرج من البوستر (`public/logo-mask.png`)، ويظهر بلون ذهبي متوهج مع لمعة متحركة.
- **البانر الأساسي:** بانر المعهد المرفق (الشعار، و«معهد اليقين الدولي»، و ALYAQIN INTERNATIONAL INSTITUTE، و«محافظة الظاهرة / ولاية عبري») ثابت أعلى الشاشة طوال الفيديو.
- **الخطوط:** Lalezar للعناوين الإعلانية، و Cairo للنصوص والأرقام.
- **الألوان:** العنابي والكحلي والذهبي من البوستر، مع لمسة سماوية تقنية.

## الصوت
موسيقى ومؤثرات أصلية مولّدة برمجياً (`scripts/make_soundtrack.py`)، بلا حقوق نشر: إيقاع سينمائي تقني بسرعة 120 BPM، ومؤثر هادئ مختلف لكل نوع انتقال، والمستوى ‎−16 LUFS المناسب للمنصات الاجتماعية.

## التعديل وإعادة التصدير
```bash
npm install
pip install numpy scipy
python3 scripts/make_soundtrack.py public/soundtrack.wav
npm run studio   # معاينة
npm run render   # تصدير إلى out/alyaqin-promo.mp4
```
- النصوص والمشاهد في `src/scenes.tsx`.
- التوقيتات وترتيب الانتقالات في `src/Video.tsx`.
- البانر والخلفية والانتقالات في `src/layers.tsx`.
- الألوان والخطوط والشعار في `src/theme.tsx`.
