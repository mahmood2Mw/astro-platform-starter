# فيديو موشن جرافيك: أساسيات الحاسب الآلي الشاملة (معهد اليقين الدولي)

فيديو إعلاني عمودي لشاشات الهواتف: 1080×1920 (9:16)، ‏30fps، ومدته **30 ثانية**. بُني بـ Remotion.

الملف الجاهز: `export/alyaqin-promo.mp4`

## الهوية
- **الشعار:** شعار المعهد الخطي الحقيقي، مستخرج من البوستر (`public/logo-mask.png`)، ويظهر بلون ذهبي متوهج مع لمعة متحركة.
- **البانر الأساسي:** بانر المعهد المرفق (الشعار، و«معهد اليقين الدولي»، و ALYAQIN INTERNATIONAL INSTITUTE، و«محافظة الظاهرة / ولاية عبري») ثابت أعلى الشاشة طوال الفيديو.
- **الخطوط:** Lalezar للعناوين الإعلانية، و Cairo للنصوص والأرقام.
- **الألوان:** العنابي والكحلي والذهبي من البوستر، مع لمسة سماوية تقنية.

## المشاهد والانتقالات
بُنيت بـ `TransitionSeries` من حزمة `@remotion/transitions` الرسمية. كل انتقال بأسلوب مختلف، وله مؤثر صوتي خاص:

| # | المشهد | الانتقال إلى التالي |
|---|---|---|
| 1 | ظهور الشعار الذهبي مع تسرّب ضوئي (Light leak) | تكبير اختراقي (مخصص) |
| 2 | «هل تريد زيادة فرصتك الوظيفية؟»: سلّم وظيفي وحقيبة عمل | مسح دائري كعقارب الساعة (Clock wipe، رسمي) |
| 3 | «اجعل مهارات الحاسب الآلي نقطة تميّزك»: شاشة ومدار ثلاثي الأبعاد | تشويش رقمي (مخصص) |
| 4 | «برنامج تدريبي: أساسيات الحاسب الآلي الشاملة» + للباحثين عن عمل | مكعب ثلاثي الأبعاد (Cube، رسمي) |
| 5 | لابتوب يعرض Word ثم Excel ثم PowerPoint ثم الإنترنت والبريد | تسرّب ضوئي ذهبي (Overlay) |
| 6 | شهادة وختم: «شهادة معتمدة من وزارة العمل» | مسح قطري (Wipe، رسمي) |
| 7 | التقويم والساعة والمدة وبطاقة سعر 130 ر.ع | دفع مع وميض ذهبي (Push‑cut، رسمي) |
| 8 | «مهاراتك 100%»، «باحث عن عمل؟ … فالمهارات تصنع الفرق» | دائرة ذهبية تنفتح (مخصص) |
| 9 | الشعار وبيانات التواصل وزر «سجّل الآن» | |

## الصوت
- **الموسيقى:** أصلية مولّدة برمجياً، إيقاع سينمائي تقني بسرعة 120 BPM.
- **المؤثرات:** مبنية من تسجيلات صوتية حقيقية مجانية الحقوق (Kenney، رخصة CC0، في `assets/sfx`)، ومعالجة لتصبح سينمائية: تبطيء وخفض طبقة، وصدى معكوس قبل القطع، وضربات منخفضة ناعمة، ولمعات زجاجية.
- مستوى الصوت ‎−15 LUFS.

## التعديل وإعادة التصدير
```bash
npm install
pip install numpy scipy   # + ffmpeg
python3 scripts/make_soundtrack.py public/soundtrack.wav
npm run studio   # معاينة
npm run render   # تصدير إلى out/alyaqin-promo.mp4
```
- النصوص والمشاهد في `src/scenes.tsx`.
- التوقيتات وترتيب الانتقالات في `src/Video.tsx`.
- البانر والخلفية والانتقالات في `src/layers.tsx`.
- الألوان والخطوط والشعار في `src/theme.tsx`.
