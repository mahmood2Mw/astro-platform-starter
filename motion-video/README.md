# فيديو موشن جرافيك — أساسيات الحاسب الآلي الشاملة (معهد اليقين الدولي)

فيديو عمودي 1080×1920 (‏30fps، ‏38 ثانية) مبني بـ Remotion، بنفس أسلوب الفيديو المرجعي:
خلفية داكنة بشبكة منظورية، بطاقات زجاجية، توهج سماوي/قرمزي، نص سفلي يظهر كلمة بكلمة، وختام بحساب إنستغرام متوهج.

الملف الجاهز: `export/alyaqin-promo.mp4`

## المشاهد
1. تعريف المعهد — 2. «هل تريد زيادة فرصتك الوظيفية؟» — 3. مهارات الحاسب الآلي (Word/Excel/PowerPoint/الإنترنت)
4. عنوان البرنامج — 5. محاور التدريب — 6. شهادة معتمدة من وزارة العمل / للباحثين عن عمل
7. التاريخ 22/11/2026، الوقت 4:30–6:30 مساءً، المدة 3 أسابيع، السعر 130 ر.ع — 8. «فالمهارات تصنع الفرق» — 9. التواصل

## التعديل وإعادة التصدير
```bash
npm install
python3 scripts/make_soundtrack.py public/soundtrack.wav   # موسيقى ومؤثرات أصلية مولّدة برمجياً
npm run studio   # معاينة وتعديل
npm run render   # تصدير إلى out/alyaqin-promo.mp4
```
النصوص والألوان والتوقيتات كلها في `src/Video.tsx` (`SCENES` و `C`).
